## 项目背景

随着大模型技术快速发展，企业对于 AI 应用的需求逐渐从简单的信息查询转向更加复杂的任务执行。相比传统聊天机器人，Agent 能够结合知识、工具和业务流程，帮助用户完成更完整的工作任务。

在此背景下，百应Claw围绕 Agent 能力建设，探索如何构建面向不同业务场景的智能服务体系。项目不仅需要打造单个高质量 Agent，还需要进一步建设包括 Skill 能力、评测体系、数据分析和标准规范在内的完整生态。


## 我的职责

负责核心 Agent 能力建设及 Agent 生态相关产品工作，参与从场景拆解、能力设计、效果评测到上线优化的完整流程。

主要工作包括：独立负责与业务共创 Agent 的设计与优化；参与百应Claw技能广场、角色广场建设；建立 Agent 效果评测与 Bad Case 分析机制；设计 Agent/Skill 数据指标体系和转化漏斗；推动 Skill 标准化测试、多端同步及生态治理。


## 01 IT服务专家 Agent 建设

### 从场景拆解到 Agent 落地

在 IT 服务专家 Agent 建设过程中，我负责从业务场景出发，对用户需求进行拆解，并进一步设计 Agent 所需的知识能力、Skill能力和任务流程。

与传统知识问答不同，企业服务场景中的用户需求通常具有较强的复杂性。用户提出的问题可能需要经过意图理解、多轮澄清、知识查询、任务执行等多个环节才能完成。我通过 GSB（Good/Same/Bad Case）评测体系持续分析实际使用效果，针对不同问题定位原因。

例如：部分问题存在意图理解偏差；部分场景知识召回准确但无法解决用户实际需求；部分任务流程存在执行断点。

针对这些问题，我通过优化 Prompt、调整知识库结构以及优化任务流程，持续提升 Agent 效果。

最终实现总命中率提升 7.46pct；效果达标率提升 15.12pct；端到端一次成功率提升 20.13%。


## 02 Agent & Skill 生态建设

### 从单个Agent能力到可复用能力体系

随着 Agent 应用场景不断扩展，单独开发每一个 Agent 难以满足快速增长的业务需求。因此，需要通过 Skill 能力建设，将不同业务能力进行模块化沉淀。

在百应Claw技能广场和角色广场建设过程中，我参与 Agent 角色体系和 Skill 生态建设。

主要工作包括：根据用户需求梳理 Agent 使用场景；参与角色 Agent 搭建和能力规划；对自研 Skill 进行测试验证；推动高质量 Skill 筛选和上线。

同时，通过优化 Skill 展示和推荐机制，提升用户发现和使用能力的效率，榜单内技能转化率提升约 20%。


## 03 Agent效果评测体系建设

### 从模型效果评估到业务效果评估

Agent 产品相比传统模型应用，更关注最终任务是否完成。

因此，单纯评价模型回答准确率无法完整反映用户体验。

针对 Agent 特性，我围绕以下几个维度建立评测体系：

- 意图识别准确性；
- 多轮对话完整性；
- 任务执行成功率与效率；
- 知识回答准确性；
- 安全与合规性；
- 用户体验感；

通过持续进行 GSB 测试和 Bad Case 分析，定位 Agent 在真实使用过程中的问题，并形成优化闭环。评测结果不仅用于优化当前 Agent，也为后续 Agent 上线提供统一判断标准。


## 04 数据指标与转化漏斗建设

### 建立Agent生态的数据反馈机制

随着 Agent 和 Skill 数量增加，如何判断用户真正需要哪些能力成为产品优化的重要问题。因此，我参与设计 Agent/Skill 数据指标体系。


围绕用户行为路径：曝光 → 点击 → 添加 → 使用 → 完成任务；建立核心转化漏斗。
包括：定义关键行为指标；统一数据统计口径；梳理能力层埋点需求；推动独立端数据采集落地。
通过数据分析，为后续：Skill排序优化；Agent推荐机制；用户转化提升；提供数据依据。


## 05 Agent生态标准化建设

### 支撑生态规模化发展

随着 Agent 和 Skill 数量增长，生态治理成为产品持续发展的重要环节。为了保证能力质量和稳定性，我参与推动 Agent 生态标准化建设。


包括：建立 Skill 端到端测试准出标准；协同算法确定角色配置融合更新机制；推动多端能力同步；落地角色产权加密保护机制。
通过标准化建设，降低生态扩展过程中的维护成本，提高新增 Agent 和 Skill 的质量稳定性。



## 关于

参与该项目让我认识到，Agent 产品的核心挑战并不是简单接入大模型，而是如何将模型能力转化为稳定、可复用、可持续优化的业务能力。

一个成熟的 Agent 产品体系，需要同时考虑：底层架构；场景理解；能力建设；效果评估；数据反馈；生态治理。未来企业 AI 产品的发展方向，不只是打造更聪明的单个 Agent，而是建立能够持续扩展和优化的 Agent 能力体系。
